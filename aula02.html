Aula 02: O Crachá dos Arquivos & Cibersegurança

Quem é quem no computador? Identifique formatos, meça os riscos reais e experimente nosso Laboratório Interativo.

1. O que é uma Extensão de Arquivo?

Todo arquivo tem um "sobrenome" após o último ponto do seu nome. Por exemplo: em trabalho.txt, o sobrenome é .txt.

Esse sobrenome é como um crachá de identificação. Ele diz para o Windows qual aplicativo tem a capacidade de abrir aquele conteúdo. Arquivos passivos guardam apenas texto ou imagens, enquanto arquivos executáveis contêm ordens diretas para o processador do computador.

2. Laboratório: Extensões & Medidores de Risco

Clique nos botões de cada modelo abaixo para baixar um arquivo real e testar no seu computador durante a aula:

.txt Seguro

Texto Puro

Contém apenas caracteres normais. Não executa ordens nem roda comandos.

Nível de Risco: 1 / 10 (Quase Zero)
.png Seguro

Imagem Digital

Guarda pixels de cores e transparência. Seguro para abrir em visualizadores.

Nível de Risco: 2 / 10 (Muito Baixo)
.json Dados

Ficha de Game / Dados

Formato de dados estruturados. Muito usado para salvar inventário e vidas em jogos.

Nível de Risco: 2 / 10 (Dados Passivos)
.exe / .bat Alerta

Executável / Script

Instruções diretas para a máquina. Pode instalar programas ou apagar arquivos do sistema.

Nível de Risco: 10 / 10 (Atenção Máxima!)

3. Simulador Interativo: O Golpe do Arquivo Oculto

Por padrão, o Windows esconde a extensão dos arquivos conhecidos. Criminosos na internet se aproveitam disso para enviar vírus com nomes como foto_da_viagem.png.exe.

Use o interruptor abaixo para simular como a vítima é enganada quando as extensões estão ocultas:

Experimento Prático de Aula

Configuração do Windows Explorer

Como o arquivo aparece na pasta:
foto_da_viagem.png.exe
Tipo real: Aplicativo Executável (.exe)
Como se proteger no seu computador:

No Explorador de Arquivos do Windows, vá no menu superior Exibir → Mostrar e marque a opção "Extensões de nomes de arquivos". Dessa forma, você sempre verá a verdadeira extensão de qualquer arquivo!
