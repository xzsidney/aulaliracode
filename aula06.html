Aula 06: Vestindo o Site com CSS — Cores, Imagens e Folhas de Estilo

Aprenda como transformar o "esqueleto" do HTML em uma página moderna com uniforme completo: cores de fundo marcantes, texto com contraste seguro, alinhamento elegante, fotos em formato de moeda e a separação profissional com arquivos .css!

1. A Mágica do CSS: A Roupa e o Uniforme do seu Site

Até agora, você aprendeu a colocar informações no navegador usando o HTML: títulos <h1>, parágrafos <p>, fotos <img> e caixas organizadoras <div>. Mas repare: todas as páginas vinham com fundo branco padrão, letras pretas e fonte sem graça!

É aqui que entra o grande parceiro do HTML: o CSS (sigla em inglês para Cascading Style Sheets, ou Folhas de Estilo em Cascata).

O HTML é o Esqueleto

O HTML cuida do conteúdo e da estrutura. Ele diz o que existe na página: onde tem um texto, onde tem uma imagem, onde tem um botão. Sem o CSS, o HTML é como uma casa só no tijolo cru e no concreto.

O CSS é o Uniforme Nobre

O CSS cuida da beleza, cores e estilo. Ele veste o esqueleto com o uniforme oficial, pinta as paredes com o azul noite, borda os títulos em ouro imperial, centraliza tudo no meio da tela e deixa as fotos redondinhas!

2. As Primeiras Propriedades Mágicas do CSS

No CSS, conversamos com o navegador através de uma fórmula muito simples e lógica:

regra-css.txt 
seletor {
  propriedade: valor;
}

1. Seletor: Quem você quer enfeitar? Exemplo: body, h1, p ou img.
2. Chaves { }: A mala de roupas onde você guarda as instruções de estilo.
3. Propriedade: O que você quer mudar? (A cor? O alinhamento? A borda?).
4. Ponto e Vírgula (;): O cadeado obrigatório que avisa ao navegador que aquela linha terminou!

A) `background-color`: A Cor de Fundo da Tela

Muda a cor de trás de qualquer elemento. Quando aplicada ao body, muda o fundo do site inteiro! Você pode usar nomes em inglês ou os códigos hexadecimais (com #):

Azul Noite LiraCode #0a0f1d
Dourado Imperial #eab308
Azul Real #1e3a8a
Bordô Rubro #b91c1c
Bloco de Notas — Exemplo de Fundo 
body {
  background-color: #0a0f1d;
}

B) `color`: A Cor das Letras do Texto

Cuidado com a pegadinha: no CSS, a palavra color muda a cor das letras (títulos, frases e parágrafos), e NÃO a cor de fundo!

Bloco de Notas — Exemplo de Cor do Texto 
h1 {
  color: #eab308; /* Título em Dourado */
}

p {
  color: #f8fafc; /* Texto das frases em Branco Nobre */
}
DICA DE OURO: REGRA DO CONTRASTE SEGURO!

Nunca coloque texto preto num fundo escuro, nem texto amarelo num fundo branco! Seus olhos não vão enxergar nada. Fundo escuro sempre pede letras claras (branco, amarelo ouro, azul bebê). Isso se chama acessibilidade e contraste visual.

C) `text-align: center;`: Centralizando no Meio da Tela

Por padrão, o navegador joga tudo colado no canto esquerdo. Para deixar seu site com cara de revista ou portal oficial, usamos a centralização:

text-align: left; (Padrão)

Meu Título no Canto

Texto alinhado à esquerda como num livro escolar.

text-align: center; (Elegante)

Meu Título Centralizado

Texto imponente centralizado no meio da tela!

D) `border-radius`: Cantos Arredondados e Moedas de Avatar!

Por padrão, toda foto na web é quadrada com pontas duras de 90 graus. O border-radius é o truque de mágica que amacia as pontas ou transforma sua foto em um círculo perfeito!

border-radius: 0px;

Quadrada padrão com cantos vivos.

border-radius: 16px;

Cantos suaves e modernos.

border-radius: 50%;

Moeda perfeita de avatar!

3. Jeito 1: CSS Interno (A Tag <style> na <head>)

O jeito mais rápido de começar no Bloco de Notas sem precisar criar outro arquivo é o CSS Interno. Nós abrimos a tag especial <style> bem no topo do nosso HTML, dentro da tag <head>.

Veja a anatomia completa de um arquivo HTML puro com estilo interno:

meu-site-estilizado.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Minha Primeira Página com Estilo | LiraCode</title>

  <!-- O CSS INTERNO FICA AQUI DENTRO DO HEAD -->
  <style>
    body {
      background-color: #0a0f1d;
      color: #f8fafc;
      font-family: Arial, sans-serif;
    }

    h1 {
      color: #eab308;
      text-align: center;
    }

    p {
      text-align: center;
      color: #cbd5e1;
      font-size: 18px;
    }

    img {
      width: 150px;
      border-radius: 50%;
      border: 3px solid #eab308;
      display: block;
      margin: 0 auto;
    }
  </style>
</head>
<body>

  <h1>Bem-vindo ao Meu Site!</h1>
  <p>Esta página foi estilizada com código CSS feito no Bloco de Notas.</p>
  <img src="avatar.png" alt="Meu Avatar">

</body>
</html>

O CSS interno é excelente para testar pequenas ideias, mas tem uma limitação: se você tiver 10 páginas HTML, teria que copiar e colar o mesmo código nas 10! Por isso, os profissionais usam o Jeito 2.

4. Jeito 2: CSS Externo (O Padrão Profissional com `style.css`)

Em empresas de tecnologia, sites de jogos e em projetos de cibersegurança, os programadores separam as coisas em dois arquivos diferentes dentro da mesma pasta:

1. Arquivo `index.html`

Cuida apenas das palavras, fotos e títulos. Nele, colocamos apenas uma tag mágica chamando o arquivo de estilo:

<link rel="stylesheet" href="style.css">
2. Arquivo `style.css`

Cuida apenas das cores, tamanhos e beleza. Nele NÃO tem tags HTML, nem <html>, nem <style>. São apenas as regras puras de estilo!

body { background-color: #0a0f1d; }

A Tag Mágica de Conexão: `<link>`

Para conectar o seu HTML ao seu arquivo CSS, basta colar esta linha mágica dentro da tag <head>:

linha-magica-conexao.html 
<link rel="stylesheet" href="style.css">

• rel="stylesheet": Avisa ao navegador: "Ei, estou conectando uma Folha de Estilo!"
• href="style.css": Diz o nome do arquivo que mora na mesma pasta.

CUIDADO COM A PEGADINHA DO BLOCO DE NOTAS NO WINDOWS!

Lembra da nossa Aula 02 (O Crachá dos Arquivos)? O Bloco de Notas adora colocar .txt escondido!

Ao salvar o seu arquivo no Bloco de Notas:
1. Clique em Arquivo > Salvar Como...
2. No campo "Tipo:", mude de "Documentos de texto (*.txt)" para "Todos os arquivos (*.*)".
3. Digite o nome exato: style.css. Se ficar style.css.txt, o navegador não conseguirá ler o estilo!

5. Mini-Laboratório: Desafio de Sábado!

Chegou a hora de colocar a mão na massa! O desafio de hoje para Enzo, Paulo Henrique, Jennifer, Ana Luiza, Isabely e Elaine é abrir a pasta do seu projeto e vestir a sua ficha pessoal com uniforme completo.

Roteiro de 5 Passos do Criador:

  1. Abra o Bloco de Notas do Windows no seu computador.
  2. Digite as regras de estilo do seu site (mude a cor de fundo, a cor das letras e o alinhamento).
  3. Salve o arquivo com o nome style.css (com a opção Todos os arquivos *.*) dentro da pasta onde está sua página!
  4. Abra sua ficha HTML no Bloco de Notas e adicione a tag <link rel="stylesheet" href="style.css"> dentro do <head>.
  5. Salve o HTML e dê dois cliques para abrir no navegador Google Chrome ou Edge. Veja as cores ganharem vida!
