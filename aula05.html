Aula 05 • Interatividade na Web: Atributos, Listas e Formulários

O momento em que suas páginas ganham vida, recebem cliques que levam a outros mundos, organizam itens e escutam o que o usuário digita na tela!

1. O que são Atributos? (Dando Superpoderes às Tags)

Lembra da Aula 01, quando anotamos no caderno Nome: Enzo e Idade: 12? Aprendemos ali o conceito de Chave e Valor! No HTML, os atributos funcionam exatamente do mesmo jeito: são informações extras colocadas dentro da tag de abertura para configurar como ela deve se comportar.

A fórmula mágica de todo atributo é sempre: nome_do_atributo="valor_da_configuracao"

A Tag <a> e o Atributo href (Links)

A tag <a> (do inglês Anchor, âncora) cria uma ponte para outro site. O atributo href diz exatamente o endereço de destino: 

<a href="https://liracode.com.br" target="_blank">
  Acessar Portal dos Pais
</a>
Resultado Visual:
Acessar Portal dos Pais ↗
A Tag <img> e os Atributos src e alt

A tag <img> traz imagens para a página. Ela usa src (o caminho do arquivo) e alt (texto para acessibilidade e leitores de tela): 

<img src="brasao-liracode.png" 
     alt="Brasão Oficial LiraCode" 
     width="60">
O navegador busca o arquivo brasao-liracode.png e o desenha na tela!

2. Listas: Organizando Informações (<ul> vs <ol>)

Na programação, quase tudo que construímos é uma lista: lista de usuários, lista de compras, inventário de itens num jogo ou ranking de pontuações. No HTML, cada item individual da lista é embalado pela tag <li> (List Item).

<ul> • Lista Não Ordenada (Bolinhas)

Vem de Unordered List. A ordem não altera o sentido. Ideal para listas de itens, poderes ou interesses: 

<ul>
  <li>Cibersegurança e Defesa</li>
  <li>Lógica de Programação</li>
  <li>Construção de Páginas Web</li>
</ul>
  • Cibersegurança e Defesa
  • Lógica de Programação
  • Construção de Páginas Web
<ol> • Lista Ordenada (Numerada 1, 2, 3)

Vem de Ordered List. A sequência importa! O navegador numera automaticamente cada item: 

<ol>
  <li>Abrir o Bloco de Notas</li>
  <li>Digitar o código HTML</li>
  <li>Salvar com a extensão .html</li>
</ol>
  1. Abrir o Bloco de Notas
  2. Digitar o código HTML
  3. Salvar com a extensão .html

3. Formulários Interativos: O Site Agora Escuta Você!

Até agora, nossas páginas só falavam com quem as lia. Mas a verdadeira mágica da internet acontece quando o usuário pode responder, digitar e interagir.

Para isso, usamos a tag <form>, que agrupa campos de entrada chamados <input>. O atributo type define o comportamento de cada campo:

🧪 Simulador ao Vivo de Formulário HTML

Teste digitando abaixo diretamente no navegador!
100% Interativo
#EAB308
Clique no quadrado para abrir a paleta de cores nativa!

4. Mini-Desafio de Laboratório: Sua Primeira `ficha-interativa.html`

Chegou a hora de juntar tudo no seu Bloco de Notas: um título, uma lista de interesses, um link externo e o seu primeiro campo de digitação!

ficha-interativa.html 
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Ficha Interativa - Aula 05 | LiraCode</title>
</head>
<body>

  <h1>Minha Primeira Ficha Interativa</h1>
  <p>Esta página foi criada no Bloco de Notas e já recebe comandos do usuário!</p>

  <h2>🎯 Meus Interesses Tecnológicos:</h2>
  <ul>
    <li>Aprender Cibersegurança e Programação</li>
    <li>Criar jogos e páginas interativas</li>
    <li>Desvendar como os computadores funcionam</li>
  </ul>

  <h2>🌐 Meu Link Favorito:</h2>
  <p>
    Conheça o <a href="https://liracode.com.br" target="_blank">Portal Oficial LiraCode</a>!
  </p>

  <h2>⚡ Teste de Formulário:</h2>
  <form>
    <p>
      Nome do Usuário:<br>
      <input type="text" placeholder="Digite seu nome...">
    </p>
    
    <p>
      Senha de Proteção:<br>
      <input type="password" placeholder="Digite sua senha...">
    </p>

    <p>
      Sua Cor Favorita:<br>
      <input type="color" value="#eab308">
    </p>

    <p>
      <button type="button" onclick="alert('Formulário enviado com sucesso no LiraCode!')">
        Enviar Dados
      </button>
    </p>
  </form>

</body>
</html>
