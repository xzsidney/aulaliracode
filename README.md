# Introdução à Lógica de Programação

Projeto simples em HTML5 e CSS3 apresentando os conceitos fundamentais da lógica de programação.

## 🚀 Conteúdos abordados
- O que é Lógica de Programação
- O Conceito de Algoritmo
- Pilares fundamentais (Variáveis, Condicionais, Laços de Repetição, Funções)
- Dicas para praticar e evoluir

## 💻 Como visualizar
Basta abrir o arquivo `index.html` em qualquer navegador web.
