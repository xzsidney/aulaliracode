# 💻 Introdução à Lógica de Programação & Segurança de Arquivos

Projeto didático criado para auxiliar nas aulas de programação e fundamentos de computação.

## 🚀 Conteúdos abordados
- **O que é Lógica de Programação** e sua importância.
- **O Conceito de Algoritmo** com analogias práticas.
- **Pilares fundamentais:** Variáveis, Condicionais, Laços de Repetição e Funções.
- **Extensões de Arquivos & Níveis de Risco:** Explicações claras e modelos para download:
  - `.txt` (Texto Puro) - Risco Muito Baixo
  - `.json` (Dados Estruturados) - Risco Baixo
  - `.png` (Imagem) - Risco Baixo / Atenção a disfarces
  - `.exe` (Executável do Windows) - Risco Alto (acompanha executável didático seguro)
- **Dicas de Cibersegurança:** Cuidados com extensão dupla e configuração de exibição no Windows Explorer.

## 📂 Arquivos de Exemplo para Download
Na pasta `exemplos/`, os alunos encontram:
- `exemplo-texto.txt`: Arquivo de texto simples.
- `exemplo-dados.json`: Arquivo de dados estruturados em JSON.
- `exemplo-imagem.png`: Imagem PNG didática.
- `exemplo-programa.exe`: Executável didático compilado em C# (inofensivo, apenas exibe um popup informativo).
- `ExemploApp.cs`: Código-fonte aberto do executável de exemplo.

## 🌐 Como visualizar
Abra o arquivo `index.html` em qualquer navegador web.
