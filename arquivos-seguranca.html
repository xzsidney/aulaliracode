Aula 02: Extensões de Arquivos & Segurança

Aprenda a identificar formatos de arquivos, seus riscos e como se proteger contra armadilhas digitais.

📁 O que é uma Extensão de Arquivo?

A extensão de um arquivo corresponde aos caracteres localizados após o último ponto do nome (por exemplo, .txt, .json, .png, .exe). Ela informa ao sistema operacional qual é a estrutura dos dados armazenados e qual software padrão deve manipulá-lo.

Na área de programação e cibersegurança, compreender extensões é fundamental: formatos passivos apenas armazenam texto ou imagens, enquanto formatos executáveis rodam comandos diretamente na sua CPU e memória.

🧪 Modelos Práticos para Baixar e Analisar

Abaixo estão quatro tipos comuns de extensões com seus respectivos níveis de risco de segurança. Clique no botão de cada cartão para baixar o arquivo de exemplo e testar no seu computador:

.TXT Risco: Muito Baixo

Arquivo de Texto Simples

Contém apenas caracteres de texto puro (ASCII ou UTF-8). Não possui formatação visual, não carrega scripts ocultos e não se autoexecuta.

🛡️ Análise de Risco:

Totalmente inofensivo ao abrir com editores como Bloco de Notas ou VS Code. O único cuidado é verificar se o arquivo não tem extensão dupla (como nota.txt.exe).

⬇️ Baixar exemplo (.txt)
.JSON Risco: Baixo

JavaScript Object Notation

Formato padrão da web para troca e armazenamento de dados estruturados em pares de chave e valor. É legível tanto por humanos quanto por máquinas.

🛡️ Análise de Risco:

O arquivo JSON em si é apenas dado passivo, não executa código. O risco só existe caso um sistema mal programado interprete os dados sem validação (falhas de injeção).

⬇️ Baixar exemplo (.json)
.PNG Risco: Baixo / Atenção

Portable Network Graphics (Imagem)

Formato popular de imagem com suporte a canal alfa (fundo transparente) e compressão sem perda de qualidade.

🛡️ Análise de Risco:

Imagens PNG são arquivos de mídia seguros. Contudo, cibercriminosos costumam disfarçar executáveis trocando o ícone para o de uma foto e usando nomes falsos (ex: foto.png.exe).

⬇️ Baixar exemplo (.png)
.EXE Risco: Muito Alto

Arquivo Executável (Windows)

Contém instruções diretas em código de máquina para o processador e o sistema operacional. Executa comandos diretamente no computador.

⚠️ Análise de Risco:

Extremamente crítico! Pode ler, alterar ou apagar arquivos, conectar-se a servidores remotos e instalar vírus ou malwares. Nunca execute arquivos .exe de fontes desconhecidas!

⬇️ Baixar executável seguro de teste (.exe)
* Nosso .exe é 100% inofensivo e exibe apenas um popup didático criado para esta aula.

🔍 Dica de Cibersegurança: O Golpe da Extensão Dupla

Por padrão, o Windows oculta a extensão dos arquivos conhecidos. Isso permite que golpistas enviem arquivos maliciosos com nomes enganosos:

Como a vítima visualiza na pasta: contrato_aluguel.pdf (com ícone falso de PDF)
O nome real e perigoso do arquivo: contrato_aluguel.pdf.exe

Como se proteger no Windows: Abra o Explorador de Arquivos, clique no menu superior Exibir → Mostrar e marque a caixinha "Extensões de nomes de arquivos". Dessa forma, você nunca mais será enganado por um arquivo executável disfarçado!
