Aula 01: Lógica de Programação

O raciocínio computacional e os blocos essenciais para construir qualquer software.

💡 O que é Lógica de Programação?

Lógica de programação é a forma de organizar pensamentos e instruções em uma sequência coerente e lógica para que um computador possa executar uma tarefa e resolver um problema.

Antes de aprender qualquer linguagem específica (como Python, JavaScript, Java ou C#), é a lógica que nos ensina a raciocinar sobre passos, decisões e repetições.

📋 O Conceito de Algoritmo

Um algoritmo nada mais é do que uma receita passo a passo para atingir um objetivo. Pense em uma receita de bolo ou em instruções para trocar uma lâmpada:

Exemplo da vida real: Fazer um café

  1. Ferver a água.
  2. Colocar o filtro no suporte.
  3. Adicionar o pó de café no filtro.
  4. Despejar a água quente sobre o pó.
  5. Adoçar a gosto e servir.

🧱 Pilares Fundamentais

1. Variáveis e Tipos

Espaços de memória para guardar dados (números, textos, datas, valores verdadeiro/falso).

nome = "Maria"
idade = 25

2. Condicionais (Se / Senão)

Tomada de decisões com base em condições lógicas.

se (idade >= 18):
  liberar_acesso()
senao:
  bloquear_acesso()

3. Laços de Repetição (Loops)

Repetir um bloco de comandos várias vezes enquanto uma condição for atendida.

enquanto (tem_itens):
  processar_item()

4. Funções

Blocos de código reutilizáveis que realizam tarefas específicas quando chamados.

funcao somar(a, b):
  retornar a + b

🚀 Dicas para Praticar

  • Divida para conquistar: quebre grandes problemas em pequenos passos fáceis de resolver.
  • Treine com pseudocódigo: escreva o que o programa deve fazer em português antes de codificar.
  • Pratique diariamente: resolva pequenos desafios lógicos com frequência.
  • Não decore, entenda: compreenda o "porquê" de cada estrutura antes de memorizar sintaxe.
