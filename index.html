💡 O que é Lógica de Programação?

Lógica de programação é a forma de organizar pensamentos e instruções em uma sequência coerente e lógica para que um computador possa executar uma tarefa e resolver um problema.

Antes de aprender qualquer linguagem específica (como Python, JavaScript, Java ou C#), é a lógica que nos ensina a raciocinar sobre passos, decisões e repetições.

📋 O Conceito de Algoritmo

Um algoritmo nada mais é do que uma receita passo a passo para atingir um objetivo. Pense em uma receita de bolo ou em instruções para trocar uma lâmpada:

Exemplo da vida real: Fazer um café

  1. Ferver a água.
  2. Colocar o filtro no suporte.
  3. Adicionar o pó de café no filtro.
  4. Despejar a água quente sobre o pó.
  5. Adoçar a gosto e servir.

🧱 Pilares Fundamentais

1. Variáveis e Tipos

Espaços de memória para guardar dados (números, textos, datas, valores verdadeiro/falso).

nome = "Maria"
idade = 25

2. Condicionais (Se / Senão)

Tomada de decisões com base em condições lógicas.

se (idade >= 18):
  liberar_acesso()
senao:
  bloquear_acesso()

3. Laços de Repetição (Loops)

Repetir um bloco de comandos várias vezes enquanto uma condição for atendida.

enquanto (tem_itens):
  processar_item()

4. Funções

Blocos de código reutilizáveis que realizam tarefas específicas quando chamados.

funcao somar(a, b):
  retornar a + b

📁 Extensões de Arquivos, Modelos & Níveis de Risco

Em computação, a extensão de um arquivo (os caracteres após o último ponto, ex: .txt, .png) indica ao sistema operacional qual é o formato dos dados e qual programa deve abri-lo. Compreender o tipo de arquivo é essencial tanto para o desenvolvimento de software quanto para a segurança da informação.

.TXT Risco: Muito Baixo

Arquivo de Texto Simples

Contém apenas caracteres de texto puro (ASCII ou UTF-8). Não possui formatação visual, não carrega scripts ocultos e não se autoexecuta.

🛡️ Análise de Risco:

Totalmente inofensivo ao abrir com editores como Bloco de Notas ou VS Code. O único cuidado é verificar se o arquivo não tem extensão dupla (como nota.txt.exe).

⬇️ Baixar exemplo (.txt)
.JSON Risco: Baixo

JavaScript Object Notation

Formato padrão da web para troca e armazenamento de dados estruturados em pares de chave e valor. É legível tanto por humanos quanto por máquinas.

🛡️ Análise de Risco:

O arquivo JSON em si é apenas dado passivo, não executa código. O risco só existe caso um sistema mal programado interprete os dados sem validação (falhas de injeção).

⬇️ Baixar exemplo (.json)
.PNG Risco: Baixo / Atenção

Portable Network Graphics (Imagem)

Formato popular de imagem com suporte a canal alfa (fundo transparente) e compressão sem perda de qualidade.

🛡️ Análise de Risco:

Imagens PNG são arquivos de mídia seguros. Contudo, cibercriminosos costumam disfarçar executáveis trocando o ícone para o de uma foto e usando nomes falsos (ex: foto.png.exe).

⬇️ Baixar exemplo (.png)
.EXE Risco: Muito Alto

Arquivo Executável (Windows)

Contém instruções diretas em código de máquina para o processador e o sistema operacional. Executa comandos diretamente no computador.

⚠️ Análise de Risco:

Extremamente crítico! Pode ler, alterar ou apagar arquivos, conectar-se a servidores remotos e instalar vírus ou malwares. Nunca execute arquivos .exe de fontes desconhecidas!

⬇️ Baixar executável seguro de teste (.exe)
* Nosso .exe é 100% inofensivo e exibe apenas um popup didático criado para esta aula.

🔍 Dica Importante para a Aula: O Golpe da Extensão Dupla

Por padrão, o Windows oculta a extensão dos arquivos conhecidos. Isso permite que golpistas enviem arquivos com nomes como:

Como a vítima vê: contrato_aluguel.pdf (com ícone de PDF)
O nome real do arquivo: contrato_aluguel.pdf.exe

Como se proteger: No Explorador de Arquivos do Windows, acesse a aba Exibir e marque a opção "Extensões de nomes de arquivos". Dessa forma, você sempre verá a verdadeira extensão de qualquer arquivo!

🚀 Dicas para Praticar

  • Divida para conquistar: quebre grandes problemas em pequenos passos fáceis de resolver.
  • Treine com pseudocódigo: escreva o que o programa deve fazer em português antes de codificar.
  • Pratique diariamente: resolva pequenos desafios lógicos com frequência.
  • Não decore, entenda: compreenda o "porquê" de cada estrutura antes de memorizar sintaxe.
